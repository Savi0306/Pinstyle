# PinStyle Analytics & Pitch Dashboard

A React & Tailwind CSS e-commerce analytics dashboard designed for **PinStyle**, a Pinterest-inspired outfit curation startup.

## Features
- **Executive KPIs**: Net Revenue, Bundle AOV, Conversion Rate, IPO, Return Rate, CAC (in INR ₹).
- **3 Target Segments**: Clean Girl Minimalist, Old Money Prep, and Trads (Heritage).
- **Interactive Data Visualizations**: Recharts integration for revenue comparison and market share.
- **Academic Pitch Brief**: Key strategic points prepared for professor discussions.

## Quick Start (Vite + React)
```bash
npm install
npm run dev
```

Or open `index.html` directly in any web browser!
